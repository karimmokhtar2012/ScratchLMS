# GitHub Organization Plan

## Workflow (GitHub Flow)
- Default branch: `main`
- Branch naming: `feat/<short-name>` or `fix/<short-name>`
- Use PRs for all changes
- Merge: squash
- Tag releases: `v0.x.y`
