# AI Context

## Project Structure & Conventions
- **Routing**: `routes/web.php` maps URLs to Controller methods. `App\Core\Router` enforces CSRF verification on all `POST` requests.
- **Authorization**: Centralized in `App\Core\Authorization`. Use `requireEnrollment` or `requireInstructor`.
- **Security**: 
    - **CSRF**: Tokens generated by `App\Core\Csrf`, injected by `App\Core\Controller`, and verified by Router.
    - **Rate Limiting**: `App\Core\RateLimiter` handles throttling (e.g., quiz attempts, uploads).
    - **Enrollment**: Enforced at Controller and Service layers to prevent unauthorized progress/access.
- **UI Components**: Primarily Blade-like PHP views using Tailwind CSS and Alpine.js.
- **Data Persistence**: Multi-database support (SQLite, MySQL, PostgreSQL). 
    - Configuration via `config/database.php` and `.env` environment variables.
    - `App\Core\Database` singleton with adapter pattern (`App\Core\Database\Adapters\`).
    - Grammar classes (`App\Core\Database\Grammar\`) handle SQL syntax differences.
    - Use `$db->insertOrIgnore()` instead of raw `INSERT OR IGNORE` for cross-DB compatibility.
    - New migrations in `database/migrations/` using Blueprint schema builder. Run via `php migrate.php`.

## Key Flows
- **Course Building**: Handled in `InstructorController`. Uses a "Batch Save" pattern where reordering is stored in memory (DOM) and persisted on click.
- **Lesson Library**: Lessons can be created independently of courses (`module_id` is nullable). Instructors can import/copy library lessons into courses.
- **Enrollment**: 
    - Free courses: Direct enrollment via `CourseController::enroll`.
    - Paid courses: Redirects to cart; enrollment happens after `CheckoutController::process`.
- **Quizzes**: Treated as separate units from Video/Article lessons in the UI. Access is secured by `Authorization` and `RateLimiter`.
- **Content Flow**: (In Progress) System to support "Free" vs "Linear" progression. DB migration complete (`courses.content_flow`).
